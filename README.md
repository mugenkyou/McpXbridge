# MCPBridge MCP Server

An implementation of the Model Context Protocol (MCP) that enables AI assistants to control and observe web browsers through MCPBridge. It exposes high‑level browser automation tools (navigate, click, type, screenshot, accessibility snapshot, and more) over MCP for seamless integration with AI clients.

## Key Features

- **Full MCP server**: Standards‑compliant, easy to integrate with MCP‑capable clients
- **Browser automation**: Navigate, click, type, select, and interact reliably
- **Observability**: Accessibility tree snapshots, console logs, and screenshots
- **Simple setup**: Run via `npx mcpbridgex` or as a local Node process
